# rEFInd-nabu

rEFInd bootloader customized for the Xiaomi Pad 5 (nabu).

Refer to: <https://github.com/rodriguezst/rEFInd-nabu/releases/tag/v1.0.0>

## Installation

1. Download `refind_aa64.efi` and any needed driver files.
2. Copy `refind_aa64.efi` to the EFI system partition (usually replacing `EFI/BOOT/BOOTAA64.efi`).
3. Copy driver files to the `drivers_aa64` subdirectory in the same directory (e.g. `EFI/BOOT/drivers_aa64`).
4. Create `refind.conf` in the same directory as `refind_aa64.efi`.
